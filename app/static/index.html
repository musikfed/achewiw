ПОЛНОЦЕННАЯ РУКОПИСЬ

Написать книгу по утверждённому каркасу

Цель берётся из поля «Целевой объём»: 20000 слов или 150 минут (при 150 словах/мин). Каждая глава создаётся несколькими фрагментами, а не одним пересказом. Черновик сохраняется в SQLite, книга не заменяется без вашего согласия.

Режиссура глав — объём, ритм, интрига

Каркас остаётся прежним. Здесь настраивается только раскрытие информации и глубина прозы для каждой главы. 1 страница ≈ 275 слов — условная оценка, не типографская норма.

План загружается…

Сохранённые настройки хранятся в SQLite отдельно от каркаса. Перераспределение не меняет событий, порядок сцен или принятый текст. Полное раскрытие разрешай только в подготовленной главе.

Память сюжета · RAG + граф причин

Авторский каркас становится последовательностью узлов графа. Ты можешь закрепить действующие факты, загадки, объекты и связи «причина → следствие». Черновик ИИ никогда автоматически не превращается в канон.

Изображение на страницу

Локальная генерация изображений

Проверка локального генератора...

Подготовка запускается только по кнопке: при необходимости установит ComfyUI, запросит подтверждение загрузки SDXL (~7 ГБ) и запустит локальный сервер. Сам checkpoint попадает в VRAM при генерации изображения.

Необязательно. Текстовая модель подготовит английский промпт для SDXL, затем запросит выгрузку только себя с твоего подтверждения. Результат редактируемый. Без этой кнопки исходное описание сразу идёт в ComfyUI.

Этапы: описание → при необходимости Ollama → проверка VRAM → ComfyUI → иллюстрация.

Обложку генерируй как художественное изображение без букв: заголовок, имя автора и год наносятся при экспорте отдельно. После рисунка проверь персонажей и детали мира. Генерация работает только при установленном локальном ComfyUI с diffusion-checkpoint. Модели qwen2.5vl и granite-vision анализируют изображения, но не рисуют их. Выбранный checkpoint определяется автоматически. Общая Ollama без разрешения не выгружается.

Визуальная загадка · подсказка сейчас, разгадка позже

Сначала создай или загрузи рисунок выше. Затем свяжи его с будущей главой, где читатель найдёт ответ. Разгадка хранится в редакторе, а на рисунке и в ранних главах не раскрывается.

Типография и выпуск

На выход идут только сохранённые тексты глав или частей. QA-отчёты, технические промпты и незаконченные разделы не подмешиваются в книгу.

Как сделать книгу с обложкой, иллюстрациями, содержанием и годом
  1. В «01 · Задание» укажи название, автора, год выпуска, редакцию и целевой объём. Сохрани.
  2. В «02 · Story.prj» создай и утверди каркас, настрой число слов по главам, интриги и память сюжета.
  3. Запусти «Написать всю книгу». Остановленная генерация возобновляется с сохранённых фрагментов — черновики не становятся чистовиком автоматически.
  4. В «05 · Проверка» изучи логические ошибки. Прими написанные главы только после чтения.
  5. В «04 · Иллюстрации» выбери «Обложка книги», опиши рисунок без букв и нажми «Подготовить генератор» → «Сгенерировать»; заголовок на титуле печатается отдельно.
  6. Для рисунка внутри главы выбери главу, «После абзаца №» и номер абзаца, затем сгенерируй или загрузи изображение.
  7. В «06 · Типография» проверь содержание, текст, год, обложку и каждую подпись; скачай EPUB, DOCX, FB2 или PDF A5.

Экспортирует только авторский чистовик. PDF A5 — проба для чтения, не PDF/X для печатной машины. Работа RAG и графа не гарантирует художественную безошибочность.
