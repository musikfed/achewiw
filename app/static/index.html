Типография и выпуск

На выход идут только сохранённые тексты глав или частей. QA-отчёты, технические промпты и незаконченные разделы не подмешиваются в книгу.

Проверка рукописи…
EPUB 3 · электронная книга FB2 · электронная книга PDF A5 · для чтения PDF A5 · проба для типографии DOCX · редактура издателя Markdown · исходный текст

PDF для типографии — реальный пагинированный файл с кириллическим шрифтом, но **не сертифицированный PDF/X**. Печатный выпуск требует согласования TrimBox, вылетов, ICC и предпечатной проверки.
