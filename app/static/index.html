CPU/RAM/GPU собираются на Ubuntu, а не в Docker. Для запуска: cd /1tbdisk/achewiw && bash scripts/monitor-v2.sh start. При неисправности: bash scripts/monitor-v2.sh status. Если GPU недоступна, проверьте nvidia-smi. «Нет данных» не означает нулевую нагрузку.

Локальная генерация изображений

Проверка локального генератора...

Необязательно. Текстовая модель подготовит английский промпт для SDXL, затем запросит выгрузку только себя с твоего подтверждения. Результат редактируемый. Без этой кнопки исходное описание сразу идёт в ComfyUI.

Этапы: описание → при необходимости Ollama → проверка VRAM → ComfyUI → иллюстрация.

Генерация работает только при установленном локальном ComfyUI с diffusion-checkpoint. Модели qwen2.5vl и granite-vision анализируют изображения, но не рисуют их. Выбранный checkpoint определяется автоматически. Общая Ollama без разрешения не выгружается.
