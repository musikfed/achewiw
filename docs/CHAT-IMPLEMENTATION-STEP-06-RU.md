# ACHEWIW · Шаг 06 — API двух чатов на действующей архитектуре

**Статус:** реализация в отдельной Draft-ветке; не развёрнуто на сервере, не слито в `main`, Ollama пока не вызывается.

## Маршруты

Все новые маршруты подключаются через `chat_api.install(api, globals())` в `app/main.py` к **существующему** FastAPI `APIRouter(prefix="/api", dependencies=[Depends(require_auth)])`. Авторизация и ограничения частной сети остаются прежними. Не создаются отдельные HTTP-слушатели или тестовый порт.

| Операция | Метод | Путь |
|---|---|---|
| Создать чат `generation/editorial` | POST | `/api/projects/{project_id}/chats` |
| История и предложения | GET | `/api/projects/{project_id}/chats/{thread_id}` |
| Переключить `clarify/autonomous` | PUT | `/api/projects/{project_id}/chats/{thread_id}/mode` |
| Отправить авторскую команду | POST | `/api/projects/{project_id}/chats/{thread_id}/messages` |
| Связать существующий immutable снимок | POST | `/api/projects/{project_id}/chat-edition` |
| Получить текущую рабочую редакцию | GET | `/api/projects/{project_id}/chat-edition` |
| Предложить текст одной главы + diff | POST | `/api/projects/{project_id}/chats/{thread_id}/candidates` |
| Принять/отклонить предложение | POST | `/api/projects/{project_id}/chats/{thread_id}/candidates/{proposal_id}/decision` |

Путь `/chat-edition` выделен отдельно, чтобы не пересекаться с `/{thread_id}`.

## Безопасность

- Каждый маршрут вызывает уже существующий `get_project`. Чужой/несуществующий проект → 404.
- Для выбранной главы исходный текст **извлекается сервером** по `scene_id` и текущему `version_id`. Браузер не может подставить ложное значение `source_text`.
- Создание/чтение диалогов работает через `work.sqlite3`; `main` не меняет схему канона и не включает новый background worker.
- Подготовленное сравнение ничего не применяет; принятие требует явного `approve: true`. Версия и исходный SHA проверяются атомарно при записи новой редакции.
- Текущий endpoint кандидата принимает **готовый текст**. Он не генерируется моделью и не допускает запуск непросмотренных команд из чата. На следующем шаге подключается отдельный адаптер LLM.
- Принятая версия становится новой **рабочей immutable редакцией**, но не перезаписывает оригинал в проекте, job или DOCWORK, и пока не становится автоматически выбранной типографией.
- Все операции действуют в прежнем авторизованном контексте одиночного пользователя; это **не** многопользовательская система прав.

## Автоматическая проверка без участия автора

`tests/test_chat_editorial_api.py` создаёт временный FastAPI TestClient и синтетическую двухглавую книгу об HDD. Проверяет связанный цикл API, неизменность исходной и соседней главы, отсутствие авто-применения в режиме генерации, 404 для чужого проекта, обязательную область, сохранение истории при смене режима, запрет правки другой главы.

```bash
python -m unittest discover -s tests -p test_chat_editorial_api.py -v
```

Для GitHub Actions добавлен отдельный workflow с установкой `app/requirements.txt`. Никаких портов, GPU, Ollama, нового Docker и отдельного `17080`.
