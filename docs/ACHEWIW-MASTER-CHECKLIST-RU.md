## Обязательный принцип: встроенный редактор не заменяется внешним

Режимы DOCWORK должны работать **параллельно**: (1) простые правки рисунка внутри книги без Windows/CorelDRAW/GPU и (2) отправка конкретной иллюстрации во внешний редактор с возвратом новой версии в тот же `draft_id + image_index`. Никакого переноса всех операций во внешний редактор.

- [x] Уже реализовано ранее: скругление углов, относительная ширина/масштаб, центрирование/выравнивание, перемещение вместе с подписью, сохранение изменений и экспорт в новый DOCX; поддерживать регрессионные host smoke.
- [ ] Проверить наличие настоящего сохранения и экспорта поворота на 90°/180°/произвольный угол; если нет — добавить независимо от Graphics Bridge.
- [ ] Проверить и добавить горизонтальное/вертикальное зеркальное отражение: превью + **тот же результат в новом DOCX**.
- [ ] При необходимости — простая локальная коррекция яркости/контраста без внешних сервисов.
- [ ] Кнопка «Править в CorelDRAW/Photoshop» для выбранной картинки: исходный PNG и стили не стираются; возвращаемый файл становится новой ревизией с отдельным `asset_id`, выбор и принятие — только автором; откат доступен.
- [ ] Тестировать все преобразования на небезопасных/экзотических форматах отдельно, не считать UI CSS-трансформацию доказательством сохранённого DOCX.

**Правило:** для простых действий на рисунке Windows-агент необязателен, иначе типография перестанет работать автономно. CorelDRAW/Photoshop — инструмент для профессиональной доработки, а не зависимость для скругления, центра или отзеркаливания.

## Следующий проверяемый шаг: Windows Graphics Bridge

1. Запустить **только** `windows/graphics-bridge/Probe-GraphicsEditors.ps1` на локальной Windows машине. Результат — названия установленных приложений и доступные COM ProgID, без запуска программ.
2. Подтвердить интерфейс CorelDRAW Technical Suite 2026 (VBA/COM импорт PNG, трассировка bitmap, экспорт SVG) на **копии** иллюстрации. Наличие COM ключа не доказывает работу функции.
3. Реализовать и испытать маленький Windows-agent **вручную запускаемый и авторизованный**, затем подключить серверное API/очередь ACHEWIW; избегать исполнения произвольных PowerShell или макросов, пришедших с пользовательским файлом.
4. Показать UI до/после и приемку нового ассета; реальный серверный E2E → только после него заявить Graphics Bridge готовым.
5. Photoshop UXP/PSJS отдельным адаптером, когда Corel круг закончен.
