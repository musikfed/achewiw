## Следующий проверяемый шаг: Windows Graphics Bridge

1. Запустить **только** `windows/graphics-bridge/Probe-GraphicsEditors.ps1` на локальной Windows машине. Результат — названия установленных приложений и доступные COM ProgID, без запуска программ.
2. Подтвердить интерфейс CorelDRAW Technical Suite 2026 (VBA/COM импорт PNG, трассировка bitmap, экспорт SVG) на **копии** иллюстрации. Наличие COM ключа не доказывает работу функции.
3. Реализовать и испытать маленький Windows-agent **вручную запускаемый и авторизованный**, затем подключить серверное API/очередь ACHEWIW; избегать исполнения произвольных PowerShell или макросов, пришедших с пользовательским файлом.
4. Показать UI до/после и приемку нового ассета; реальный серверный E2E → только после него заявить Graphics Bridge готовым.
5. Photoshop UXP/PSJS отдельным адаптером, когда Corel круг закончен.

- Не удалять Ollama, GGUF, ComfyUI/SDXL, модели без зависимости и согласования: на одной машине несколько независимых проектов.
- Не пересобирать Docker после каждой правки документации или Windows скрипта.
- Хранить все эксперименты в отдельных ветках/PR, main не менять.
- Реальный исходник DOCX + текст книги + состояния job неизменны до осознанной операции владельца.
- Включение облачной «Верфи» — **после** работающего редакторского/типографского конвейера, в независимой очереди.
- Для аппаратного экспериментирования см. `docs/HUANANZHI-E5-2650V2-RTX3060-TOPOLOGY-RU.md`.
