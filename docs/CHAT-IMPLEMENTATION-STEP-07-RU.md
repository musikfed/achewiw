# ACHEWIW · Шаг 07 — локальная Ollama для предложения редактуры

**Ветка:** `feature/chat-ollama-editorial-20261125`. **Статус:** Draft PR, без развёртывания и без изменений авторских рукописей.

## Что добавлено

- `app/chat_ollama_editor.py` — короткая единичная редакторская операция через установленную Ollama (`/api/tags` → `/api/generate`, `stream:false`, `think:false`). Только существующая выбранная модель, никаких скачиваний/обучения, никаких новых задач генерации книг и автоматического применения.
- `POST /api/projects/{project_id}/chats/{thread_id}/ollama-candidate` — защищённый маршрут в **старом** `/api` роутере. Требует `chat_proposal_id`, `base_version_id`, `scene_id`, `model`.
- Авторское поручение и текст главы извлекаются **из SQLite** внутри API, а не доверяются новому полю `source_text` браузера. Проверяются проект, чат `editorial`, авторское сообщение, scope=chapter, SHA исходника, текущая ревизия и отсутствие повторного кандидата.
- Готовый текст передаётся в существующий `chat_linked_edits.prepare`, возвращает `diff` и `status:proposed`. Рукопись не изменяется до отдельного `decision {approve:true}`.
- Предельный размер исходного текста **4500 символов**, поручения **1600 символов**, ответа **8000 символов**. Это *проверка короткой главы*, не многотомная бесконтрольная обработка.
- Прежде чем отправить запрос, проверяются занятость основных `ai_jobs` и общая SQLite GPU lease; резервируется ровно один `chat_editorial` lease, освобождается в `finally` как при успехе, так и при ошибке. Модель не выгружается без согласия пользователя. Другая модель/процесс вне ACHEWIW по-прежнему может использовать GPU; гарантии полной изоляции чужих сервисов нет.
- Лимит генерации `num_predict=1800`; модель получает короткий редакторский промпт, но её фактическая надёжность в отношении источников и чисел требует проверки человеком.

## Тестирование без собственного сервера

`tests/test_chat_ollama_editor.py`: мокированный ответ Ollama, отсутствие установленной модели, отказ при слишком длинной главе, реальный in-process FastAPI+SQLite endpoint с подготовкой diff, конфликт занятости GPU, ошибка модели с освобождением lease.

```bash
python -m unittest discover -s tests -p 'test_chat_ollama_editor.py' -v
```

GitHub Actions проверяет синтетические операции без подключения к Ollama, Docker, сети, HTTP-портам или авторским файлам. **Реальный вызов на тестовом сервере пока НЕ выполнялся**. Отдельный `17080` не создаётся, продакшен `7080` не изменяется.
