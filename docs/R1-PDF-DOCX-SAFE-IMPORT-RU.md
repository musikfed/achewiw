# ACHEWIW · R1 — безопасный импорт PDF → DOCX

**Дата:** 23.11.2026. **Статус:** реализация в отдельной тестовой ветке `fix/r1-pdf-docx-preservation-20261123` и draft PR; **не установлен на Ubuntu-хосте**. Ветку `main` и пользовательские произведения не менять.

## Цель и фактическое решение

Ранее `pdf_to_docx()` копировал только блоки текста и сортировал их по координате Y, поэтому терял встроенные рисунки и смешивал абзацы из двух колонок.

В R1 появился `app/pdf_layout_import.py`, который:

1. Обходит все страницы и выполняет предобработку до формирования DOCX (ошибочный PDF не возвращает частичный файл).
2. Извлекает текст и **отображаемые растровые изображения** через PyMuPDF `get_text("dict")`. Вставляет изображения в DOCX, сохраняет пиксели проверочного PNG, связь следующей подписи с рисунком через `keep_with_next`.
3. Восстанавливает простой двухколоночный **порядок чтения целыми колонками** (слева сверху вниз, затем справа), а не построчно между колонками.
4. Неподдерживаемые векторные схемы, таблицы с линиями, аннотации, PDF-гиперссылки, поля формы, неоднозначные/пересекающиеся колонки и крупные изображения **отклоняет с понятной ошибкой**. Такой PDF нельзя выдавать за успешно и полностью восстановленный DOCX.
5. Отдельный режим `pdf_mode=text_only` извлекает только текст при **явно отмеченном** `confirm_text_loss=true`. Блокировка без этого подтверждения проверяется API-тестами. Режим по умолчанию — `preserve`.
6. В UI `/docwork/` добавлены выбор текстового режима, отдельный флажок согласия на потерю объектов, число изображений и страниц с векторными элементами при инспекции.
7. PDF→PDF остаётся побайтно неизменённым; для файлов без текстового слоя требуется OCR (не добавлен).

## Важные ограничения

**Результат — редактируемое перекомпонованное DOCX, а не пиксельная копия PDF.** Не обещается восстановление исходного расстояния, точных шрифтов, таблиц, номеров сносок, полей, сложной типографики, печатного PDF/X и библиографии по ГОСТ. Для многостолбцовых и структурно сложных PDF импорт остаётся консервативным: отклонить либо извлечь только текст после согласия.

«Рисунок + подпись» дополнительно проверяется на связь в R2, включая переход через границу страницы в DOCX/PDF. Текущая проверка R1 подтверждает сохранение встроенного рисунка, подписи, исходного цвета/разрешения и логического порядка на простом синтетическом PDF. Полная визуальная приёмка и нормативная проверка остаются в 00-Д как отдельные незакрытые критерии.

## Безопасность

- Никаких изменений исходного PDF, `data/`, авторских проектов, SQLite, Ollama, ComfyUI, GPU, Linux-сервиса, соседних репозиториев или облака.
- Проверяется на синтетических PDF, собранных в памяти теста.
- Пределы ввода из Workshop: 20 МиБ PDF, 400 страниц, дополнительная защита по количеству блоков, объёму изображений и размеру растров.
- Изолированный PR на базе ветки испытаний 00-Г/00-Д; `main` и рабочий контейнер не обновляются.
- Если человек осознанно выбрал `text_only`, выходной файл **не является подтверждением сохранности иллюстраций и типографики**.
