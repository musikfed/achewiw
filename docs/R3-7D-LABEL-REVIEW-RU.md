# ACHEWIW R3.7D — назначение подписей узлам схемы

Статус: отдельная экспериментальная ветка; R3.7C успешно прошла на Huananzhi 11 Node-тестов и 27 прежних DOCWORK smoke-тестов по журналу пользователя. R3.7D ещё не проходила испытания на хосте.

## Назначение
На основе вручную нарисованных узлов и надписей редактор предоставляет список надписей и выбор узла для каждой. Только человек выбирает узел и может сбросить назначение. Автоматического распознавания надписей, семантики или электрических соединений нет. Неоднозначные связи по-прежнему невозможно подтвердить автоматически.

Решения хранятся в localStorage для конкретного черновика DOCX, рисунка, базовой версии и отпечатка текста и геометрии фигур. Токены и пиксели там не сохраняются. При изменении геометрии или текста подписи назначения не применяются. В экспорт JSON добавляются вручную подтверждённые назначения в `geometryAudit.labels`, а для иных программ ясно отмечается происхождение `manual-confirmed`. Исходный DOCX, SQLite и принятие PNG не меняются.

## Проверка
1. `node --check app/static/diagram_graph.js && node --check app/static/docwork_workbench.js`.
2. `node --test tests/diagram-graph.test.cjs` — теперь 14 тестов: к прежним 11 добавлены назначение, запрет несуществующего узла и сброс подписи.
3. Предыдущий `scripts/docwork-image-host-smoke.py` на синтетическом DOCX.
4. В браузере нарисовать два блока, стрелку, две подписи, нажать «Проверить связи схемы». Для каждой надписи назначить узел и проверить JSON.
5. Проверить F5 без смены браузера, восстановление ручных назначений; изменить подпись или положение узла и убедиться в инвалидировании старого решения.
6. Проверить «Не назначено», экспорт JSON, отсутствие автоматического изменения книги, работу кнопки удаления отдельной книги.
7. Проверить, что назначения не переносятся в чужой черновик или на внешнее изображение.

## Ограничения
Назначение подписей хранится в браузере и исчезает при очистке данных сайта. JSON — переносимый снимок, но автоматический импорт его обратно пока не реализован. Бинарные веса, RAG и литературная генерация не задействованы. До отдельной визуальной приёмки не объявлять редактор готовым к типографскому выпуску.
