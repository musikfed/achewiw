# ACHEWIW R3.7C — приёмка связей схем человеком

**База:** R3.7B, проверенная на физическом Huananzhi: 8/8 Node и 27/27 DOCWORK HOST smoke по журналу владельца. Сам этап R3.7C ещё не развёрнут и не проходил хостовую приёмку.

## Назначение
После ручного рисования схемы редактор R3.7B находит геометрических кандидатов связи. На этапе R3.7C оператор может для каждого однозначного кандидата явно выбрать **«Подтвердить»**, **«Отклонить»** или **«Сбросить решение»**. Система не подтверждает связи автоматически и не разрешает подтвердить неоднозначные/разомкнутые соединения. При изменении геометрии прежние решения не применяются, пока геометрия отличается от исходной.

## Данные и ограничения
Решения хранятся в localStorage конкретного браузера с привязкой к защищённому черновику, рисунку и текущему ID изображения и точной геометрии фигур. Токены, пароли, исходные изображения и рукописи туда не записываются. При очистке данных браузера решения исчезают. Экспорт JSON включает результат `geometryAudit` с вручную принятыми/отклонёнными связями; это переносимый снимок решений, не автоматическая синхронизация и не изменение SQLite. Структурный SVG остаётся только отдельным слоем ручных векторных фигур. Внешние изображения и временная векторизация не обещают сохранения решений между F5. Нет OCR, LLM, автоматической замены книг и GPU-нагрузки.

## Проверка
1. Выполнить `node --test tests/diagram-graph.test.cjs` — тестируются однозначные и неоднозначные связи, запрещённое автоутверждение, ручное принятие/отклонение.
2. Выполнить `node --check app/static/diagram_graph.js` и `node --check app/static/docwork_workbench.js`.
3. Проверить предыдущий host-smoke DOCWORK на синтетическом файле.
4. В браузере открыть DOCX с двумя схемными фигурами. Нарисовать соединение, нажать «Проверить связи схемы», принять связь, экспортировать JSON и убедиться, что `confirmedRelations=1`.
5. Повторить F5, открыть тот же черновик, убедиться, что решение сохранилось (при сохранённой разметке). Сдвинуть любой узел и проверить, что старое решение не переносится на новую геометрию.
6. Создать неоднозначный случай с наложенными узлами и убедиться, что его нельзя подтвердить.
7. Отменить подтверждение, удалить/снять часть рисунка и проверить, что оригинальный DOCX не изменён.
8. Убедиться, что книги библиотеки и запись удалённой тестовой книги не восстановились.
