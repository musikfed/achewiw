# ACHEWIW R3.4 — практическая мастерская шрифтов и сохранения

Дата: 23 ноября 2026 года.
PR: https://github.com/musikfed/achewiw/pull/30

## Что исправлено на основании реального использования

- Кнопка «Скрыть панель» убирает громоздкую закреплённую полосу «Результат редактора» при прокрутке.
- Кнопка «Скрыть инструменты» убирает форматирующую полосу с отменой, выравниванием и заголовками.
- Кнопка «Скрыть настройки» слева переводит лист в полноширинный режим и скрывает длинную галерею изображений (полезно при 60+ иллюстрациях). Все три панели можно вернуть; состояние скрытия живёт в sessionStorage текущей вкладки, а не в книге.
- **Две колонки шрифтов**: для нормативно ориентированного оформления — Liberation Serif, Times New Roman (только если установлен), DejaVu Serif, Liberation Sans; дополнительные — Carlito, Caladea, FreeSerif, FreeSans, FreeMono, Liberation Mono, DejaVu Sans, DejaVu Sans Mono. Для основного текста, глав и подглав выбранный шрифт устанавливается отдельно.
- В Docker Studio дополнительно устанавливаются свободные пакеты Caladea/Carlito/FreeFont. Шрифты Microsoft не скачиваются, подмена при рендеринге PDF возможна. Никаких универсально «сертифицированных ГОСТ шрифтов» не существует: выбор зависит от норм конкретного вида документа, а соответствие проверяется на R4.
- В верхней панели и редакторе — явные кнопки «Сохранить изменения». Индикатор сообщает реальное состояние: ожидает сохранения, запись на сервер, подтверждённая версия SQLite, ошибка или конфликт вкладок. Автосохранение R3 с задержкой 900 мс сохранено.
- Скругление рисунков на настоящем PNG: 0–24%, шаг 0,5%. Для очень широких/высоких изображений предел **8%**, при умеренной вытянутости **12%/18%**, для почти квадратных **24%**. Радиус вычисляется по **меньшей стороне**, пропорции картинки не меняются. В браузере предпросмотр использует то же правило.
- Дополнительное исправление после осмотра большого реального документа с 17 разделами: перемещение рисунка и подписи возможно **в пределах его раздела**. Между разделами перенос не допускается, чтобы не переносить колонтитулы и границы разделов.

## Как проверить на испытательном Huananzhi

**Условие:** дождаться зелёного CI PR №30. Текущий сервер — проверенная R3.3, его новая ветка сама собой не заменяет.

После сохранения текущего черновика, проверки чистоты Git и готовности только собственного Studio можно перейти на ветку `feature/docwork-fonts-save-status-r34-20261123`, выполнить `bash scripts/achewiw-control.sh rebuild`, `bash scripts/achewiw-control.sh auth-check`, затем синтетический smoke:

`docker exec -i -w /app achewiw-studio python - < scripts/docwork-image-host-smoke.py`

Проверить Ctrl+F5, сворачивание всех трёх панелей, сохранение с подтверждённой версией, выбор одного шрифта для основного текста и другого для заголовка, изящное скругление широкой схемы на 0,5–8%, экспорт DOCX/PDF. Проверить через `fc-match 'Caladea'`, `fc-match 'Carlito'`, `fc-match 'FreeSerif'`, чтобы подтвердить наличие шрифтов после Docker-сборки. Для собственной книги с несколькими разделами проверить перенос рисунка внутри раздела, не затрагивая границы секций.

**Ограничения:** нет форматирования выделенных слов B/I/U, нет пиксельно точного «Word в браузере», нет полного внедрения произвольных шрифтов. R4 (актуальные ГОСТ, библиография, профиль издания, нормативная проверка) отдельно.

Исходные DOCX/PDF и пользовательские книги в библиотеке не переписываются; версионированные данные R3 находятся в той же SQLite. До ручной приёмки в браузере критерии D10/D13/D14 остаются неподтверждёнными, нормативный допуск D11 не реализован.
