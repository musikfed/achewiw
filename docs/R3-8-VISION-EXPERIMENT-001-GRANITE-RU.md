# R3.8 — эксперимент 001: Granite ответила, но JSON не прошёл валидацию

24.11.2026, Huananzhi RTX 3060 12 GiB, ACHEWIW Studio 7080.

## Исходный результат пользователя
- Предпроверка: Ollama обнаружила `granite3.2-vision:2b` и `qwen2.5vl:7b`.
- При запуске эталонного рисунка через `scripts/docwork-vision-benchmark.py --model granite3.2-vision:2b --confirm-gpu` сервер вернул **HTTP 422**, деталь **«Модель не вернула проверяемую структуру схемы»**, время **17,26 с**.
- Мониторинг показал загруженную `granite3.2-vision:2b` (около 2,9 GiB VRAM), общая занятость RTX 3060 около 3,9/12 GiB. Следовательно, это не свидетельство того, что модель не запускается.
- Созданный тестовый DOCX явно закрыт, `Synthetic draft closed: True`.
- Исходный текст ответа модели не был сохранён (защитная практика). Неизвестно, был ли ответ обычным текстом, JSON без ключа proposals или обрезанным JSON.

## Узкая доработка
1. Вызов существующего локального `/api/chat` дополняется поддерживаемым Ollama `"format": "json"`. По данным документации Ollama это включает JSON-режим, но его работоспособность именно для установленной версии Granite надо проверить на хосте.
2. Парсер остаётся строгим: ответ модели — **непроверенный**; отсутствие `proposals`, некорректные координаты и неизвестные типы не подтверждают объекты.
3. Ошибка в API получает безопасную категорию: отсутствует содержимое, JSON повреждён, нет массива `proposals`, пустой ответ. Ни сырая книга, ни изображение, ни capability-токен, ни произвольный вывод LLM в сообщение об ошибке не попадают.
4. Диагностический скрипт печатает только эту категорию. Нет автоматического повтора, скачивания моделей, вмешательства в Ollama или GPU.

## Приёмка
После зелёного CI — **одна** контролируемая пересборка ветки на Huananzhi; на GPU не должны работать другие задачи. Затем **один** запуск Granite на прежнем синтетическом рисунке; при неудаче зафиксировать новую категорию, не повторять в цикле. Если она по-прежнему не возвращает валидные предложения, следующий эксперимент — точно тот же рисунок на `qwen2.5vl:7b`, только после проверки VRAM и GPU и отдельного подтверждения пользователя.

**Важно:** успешное получение JSON ещё не доказывает правильное распознавание. Сравнивать с `ground-truth.json`, сохранять `evaluation.json`; ручная приёмка обязательна.
