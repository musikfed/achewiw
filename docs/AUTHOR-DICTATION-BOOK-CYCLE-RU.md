# ACHEWIW — авторская диктовка поверх существующего конвейера

Дата: 24.11.2026. Дополнение к зависимым PR #54 (задача главы), #55 (фильтр повтора), #56 (пауза), без изменения работающей Studio.

## Что добавлено в генерационную студию

`app/static/author_dictation.js` подключён к уже существующей странице `/`. Если браузер поддерживает `SpeechRecognition`/`webkitSpeechRecognition`, рядом с текстовыми полями редакционного задания, описания глав, плана, рукописи и задач появляется **🎙 Надиктовать**. По нажатию автор разрешает работу микрофона, диктует, затем останавливает запись. Распознанные готовые фразы вставляются туда, где курсор, и вызывают штатный `input` event: дальнейшее сохранение и генерация используют **существующие** кнопки, никакого нового маршрута LLM.

Диктовка работает также в `/docwork/` для текста редактируемого абзаца сторонней DOCX/PDF. Не меняет исходные файлы самостоятельно.

## Приватность и технические ограничения

- **Это браузерное распознавание, не локальный Whisper и не отдельная модель ACHEWIW.** Некоторые браузеры обрабатывают звук на своих удалённых серверах. Перед первой записью показывается явное предупреждение/согласие. По умолчанию микрофон выключен.
- Сервер ACHEWIW принимает только результат через обычную логику редактирования текста, **отдельного API для аудио и сохранения записи нет**.
- Диктовка доступна только там, где браузер реализует Web Speech API и владелец разрешил микрофон. В несовместимом браузере поле работает с клавиатурой, без кнопки.
- Язык: русский `ru-RU`, пока один профиль.
- Не выполняет автоматически: принятие главы, загрузку изображения, сохранение версии, запись авторского канона и публикацию.

## Прямой полезный маршрут

1. Введите или надиктуйте тему и цель книги.
2. Утвердите каркас глав, настройте объёмы и задачи.
3. Запустите генерацию; по необходимости нажмите «⏸ После фрагмента — пауза».
4. Диктуйте или введите уточнение следующего шага главы.
5. Сохраните указание и нажмите «Продолжить». Сохранённая проза, ID задания и RAG-границы остаются прежними.
6. Читайте, принимайте и форматируйте результат. В `/docwork/` можно отдельно открыть собственную стороннюю DOCX/PDF и редактировать абзацы, независимо от генератора.

## Подтверждение

- Целевые SQLite-тесты PR #54/#55/#56 уже прошли CI; новая проверка `tests/test_book_author_cycle.py` покрывает единый переход pause → intervention → resume на одной временной БД без Ollama.
- Web Speech — браузерозависимая функция, синтаксис кода в CI **не доказывает** доступность распознавания или реальное качество диктовки в Chromium пользователя.
- PR добавлен в код, на сервер `/1tbdisk/achewiw` не развёрнут; `projects=0/ai_jobs=0` в ранее проверенной SQLite. Нельзя говорить, что восстановлена старая книга с 67%.
- Для будущей офлайн-диктовки можно подключить локальный STT на CPU, если конкретное устройство покажет приемлемую скорость; не устанавливать это автоматически.
