# EPUB Viewer — UX-контракт ACHEWIW

**Статус:** дизайн-план. **Не подключено к веб-приложению.**

## Читательский экран

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ ACHEWIW  •  Техническая книга                ☰ Оглавление  ◐  Аа  🔖  Поиск │
├───────────────────────┬─────────────────────────────────────┬────────────────┤
│ СОДЕРЖАНИЕ            │  ГЛАВА 4 — ПОТОК ДАННЫХ             │ РЕДАКТОР       │
│ > Глава 1             │                                     │ Источник #12   │
│ > Глава 2             │  Каноническая схема вычислений      │ DOI проверен   │
│ > Глава 3             │         [SVG diagram]               │ Версия схемы 3 │
│ > Глава 4             │                                     │                │
│   § 4.1               │  Термин: DAG  ◌ см. словарь         │ Карточка 74    │
│   § 4.2               │  Примечание [12]                    │ [Исправить]    │
│ > Словарь             │                                     │ [Комментарий]  │
│ > Библиография        │  ← Назад        27%        Далее →  │                │
└───────────────────────┴─────────────────────────────────────┴────────────────┘
```

Режим **Чтение** скрывает всё редакторское и оставляет аккуратное электронное издание. Режим **Редактор** показывает при наведении источник факта, связанные карточки, версию и комментарии.

## Обязательный UX

- Кнопки «Назад/Вперёд», оглавление, главы, поиск по содержимому.
- Темы светлая/тёмная/сепия; размер шрифта, межстрочные интервалы, ширина полосы, переключение шрифтов.
- Закладки, заметки, локальная история, восстановление позиции между сеансами (опционально и приватно).
- Сноски, DOI и библиографические сведения переходят по клику; доступно объяснение термина при выборе.
- Математика и технические иллюстрации масштабируются без потери исходников: SVG и MathML (где поддержка зависит от reader); fallback для несовместимых EPUB-приложений.
- Доступность: keyboard only, видимый focus, семантические landmarks, screen reader, системные настройки масштабирования, alt-тексты у значимых изображений.
- Ссылка читателя → контекст карточки в редакторе через карту `edition locator -> source card id / revision id`.
- Подсветка *неподтверждённых* источников только в режиме редактора; читательское издание проходит QA до выпуска.

## Реализация (предложение)

- Рендерер `epub.js` локально упакован в фронтенд; фактическая совместимость, поддержка CFIs, table/math/footnotes, мобайл и офлайн проверяются тестами. Не полагаться на внешний CDN.
- API **предлагаемые, не действующие**: `GET /api/editions/{id}/epub`, `GET /api/editions/{id}/manifest`, `GET /api/editions/{id}/locators`, `POST /api/editions/{id}/proof-comments`.
- В режиме черновика `build preview` создаёт временный EPUB, а `release` — только проверенный/подписанный `edition_id`.
- Редакторские заметки сохраняются в отдельном слое и **не вставляются** в выпущенный EPUB, пока автор явно не изменит исходную карточку.
- Идентификатор местоположения: EPUB CFI + целевой `edition_hash`, при новом EPUB версия позиции требует ремаппинга, а не автоматического перемещения на непохожий текст.
- Безопасный импорт: не доверять пользовательским EPUB; ограничения ZIP/вес/ссылки, sandbox, CSP, запрет автосетевых запросов и скриптов внутри книги по умолчанию.
- Ссылки на следующий том/QR должны вести на разрешённые автором публичные маршруты, а не незащищённые локальные адреса домашнего сервера.

## Тесты приёмки

1. Открывается реальный EPUB, экспортированный из утверждённого содержимого, с кириллицей и иллюстрациями.
2. Переход к любой главе через оглавление, закладка и назад работают после повторного открытия.
3. Термины, внутренние ссылки, библиография, сноски и alt-тексты доступны с клавиатуры.
4. Reader и выпущенный EPUB показывают один и тот же текст (сравнение manifest/snapshot).
5. Изменение карточки вызывает новую сборку, не меняет старую опубликованную редакцию и не уничтожает старые заметки.
6. Произвольный импортированный EPUB не может выполнить JS, прочитать файлы хоста или вызвать неразрешённые внешние URL.
7. EPUBCheck + проверка содержания, прав и утверждений пройдены, прежде чем показывать статус «Готово к выпуску».
