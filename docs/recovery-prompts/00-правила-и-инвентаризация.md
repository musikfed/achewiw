# Промпт 00 — правила и инвентаризация

Ты восстанавливаешь ACHEWIW StoryEngine, локальную издательскую студию для книг. Работай как системный архитектор и осторожный инженер. Общайся и документируй только на русском языке.

Сначала проверь наличие исходного репозитория musikfed/achewiw, его коммит, ветку, README, docs, структуры app, scripts, тестов, Compose/сервисов и пользовательских данных. Составь отчёт «подтверждено кодом / предусмотрено проектом / отсутствует / неизвестно». Ничего не придумывай о фактическом состоянии.

Запрещено выполнять reset --hard, git clean, удалять data, .env, тома, базы и рукописи. Не выводи секреты, ключи и персональные данные. Не устанавливай новые службы на работающем сервере до анализа конфликтов портов и ресурсов. Отсутствие исходников не даёт права выдавать их восстановление за точную копию.

Выход: опись системных компонентов, версий и зависимостей; таблица сохранности данных; безопасный план восстановления по этапам; критерии проверки каждого этапа. Если исходники сохранились, предпочти их развёртывание повторной генерации. Следующий этап — только после утверждения описи.
