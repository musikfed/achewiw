# ACHEWIW — архив последовательных промптов восстановления

Назначение: текстовый резервный комплект для **воссоздания проекта с нуля** при потере рабочего окружения или необходимости перенести архитектуру на другой сервер. Всё содержание на русском языке. Только Markdown и текстовые инструкции; без исполняемых скриптов, моделей, токенов, паролей, дампов и личных данных.

## Перед началом

Это **снимок проектных требований**, а не доказательство, что каждый модуль уже готов. Источник истины о фактической реализации — код и документация конкретного коммита в репозитории. Если исходники сохранились, восстанавливать их из Git прежде, чем писать код заново. Без настоящих бэкапов невозможно воссоздать исходные пользовательские книги, базы и обученные веса только по этим промптам.

Как применять: передать исполнителю (человеку или ИИ-разработчику) **сначала промпт 00**, затем следующий после фиксации проверяемого результата текущего этапа. Не запускать все задания одной командой. После каждого шага сохранить документацию, тесты и изменения в Git. Не подменять данные проекта сгенерированными примерами. При неопределённости останавливаться на безопасном чтении и сообщать вопросы.

Общий инвариант: ни одна операция восстановления не должна уничтожать существующую библиотеку книг, историю редакций, базы или пользовательские файлы. Отдельный план развёртывания: [../DEPLOYMENT-ROADMAP-RU.md](../DEPLOYMENT-ROADMAP-RU.md).
