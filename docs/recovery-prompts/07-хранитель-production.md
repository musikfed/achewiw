# Промпт 07 — «Хранитель» (строго отложено до production)

Этот этап **не выполнять в текущей разработке**. Вернуться только после подтверждённого выхода ACHEWIW в production и отдельного решения о развёртывании.

Спроектируй самостоятельную службу «Хранитель» без LLM, Ollama и GPU, которую можно запустить на другом Linux-компьютере той же локальной сети. Подходящие технологии для оценки: Python, SQLite, systemd, Restic/Borg, SSH с минимальными полномочиями. Не выбирать инструменты до проверки совместимости и угроз. Сервис управляет несколькими источниками, но не получает права удалять произвольные файлы источника.

Раздели оперативные checkpoints обучения, согласованные резервные копии SQLite, архивы LoRA/датасетов, метрики и документацию. Обязательны: граф зависимостей артефактов, идентификаторы и контрольные суммы, дедупликация, ротация, квоты, защита последней и лучшей проверенной версии, расписание (первоначальная гипотеза: раз в 3 дня), ручной запуск, журналы, верификация восстановимости, тестовое восстановление, мониторинг заполнения и безопасное приостановление при нехватке места. Не переписывать активные файлы; не считать компрессию бинарных весов гарантированной.

Предусмотри независимое хранение критических копий на другом физическом носителе, резервирование собственной политики/каталога Хранителя и возможность восстановления без сети. Любое удаление — только после проверки ссылок и действующих защит; невозможность выполнить бэкап не должна запускать удаление. Сначала представь проект архитектуры и риск-анализ; код и запуск только по отдельному разрешению после production.

Результат: техническое задание будущего сервиса, схема данных и интерфейсов, план испытаний с отказами, безопасная процедура ротации. Статус: **ЗАПЛАНИРОВАНО / НЕ РЕАЛИЗОВАНО**.
