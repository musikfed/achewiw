# Промпт 04 — редактор, интерфейс и форматы книги

Воссоздай браузерную студию: главная и библиотека, создание/открытие проекта, план, прогресс задач, главы, редакторские замечания, история правок, иллюстрации и экспорт. Состояние важных пользовательских изменений не должно теряться от F5; работа фоновых заданий не зависит от нахождения пользователя на вкладке. Пустая библиотека не должна показывать чужие рукописи или фиктивную статистику как реальные данные.

Редактор предлагает точные правки с указанием основания, но изменения текста подтверждает автор. Для экспорта обеспечить DOCX, PDF, EPUB и FB2 в рамках подтверждённых возможностей; явно маркировать ограничения предпечатных стандартов и не обещать PDF/X без проверки. Графический движок — необязательный компонент, запускаемый по явной кнопке/команде, без скрытого скачивания моделей.

Результат: спецификация экранов, API для сохранения изменений, тесты навигации и восстановления, тестовые экспорты без реальных авторских данных, список требований доступности и ошибок.
