# Промпт 05 — «Верфь» непрерывного обучения открытых LLM

Спроектируй необязательный модуль ACHEWIW «Верфь», не мешающий основному литературному конвейеру. Назначение: постепенно обучать/дообучать совместимые открытые модели на своих или разрешённых датасетах, используя только доступные бесплатные ресурсы облаков и/или локальную GPU. Кандидаты для проверки при реализации: Kaggle, Google Colab, Modal; Lightning AI не считать доступным. Бесплатность, GPU-квоты и сроки сброса проверять заново; не обещать фиксированный сброс, если его нет. Не использовать платные ресурсы без явного решения пользователя.

Предусмотри LoRA/QLoRA, воспроизводимые конфигурации, версии набора данных и базовой модели, метрики loss/learning rate/шагов/времени/VRAM, графики по сеансам. Отдельно храни полное состояние для resume: адаптер, optimizer, scheduler, RNG, global step, параметры обучения, идентификаторы артефактов. Сохранение должно происходить по шагам и перед штатным завершением квоты. При внезапном прерывании восстановление возможно только с последнего успевшего записаться checkpoint. Проверяй совместимость оборудования и формата точки восстановления при смене облака.

Сформулируй роли: «Верфь» учит, «Экзаменатор» сравнивает на отложенных примерах, «Редактор» применяет принятую версию. Не называй снижение loss доказательством улучшения литературного качества. Экспортируй проверенные LoRA/совместимые сборки для локального использования только после испытаний.

Выход: архитектура адаптеров провайдеров, схема задания и checkpoint, матрица ограничений бесплатных ресурсов, сценарии прерывания/возобновления и бюджет хранения.
