# ACHEWIW R3.7E — импорт структурного JSON схемы

Статус: экспериментальная ветка от R3.7D. На предыдущей версии владелец подтвердил 14/14 Node-тестов, 27/27 DOCWORK HOST smoke и HTTP 200. Новая версия **не развёрнута**.

## Назначение
Закрыть разрыв между экспортом структуры SVG/JSON и восстановлением сессии. В мастерскую иллюстраций добавлен импорт JSON: в отличие от незащищённого произвольного файла, формат требует явной отметки о ручном происхождении, точного ID защищённого черновика DOCX, номера рисунка, версии применённого изображения и размера холста. Файл JSON не содержит токены, пароли или исходные пиксели. Ранее экспортированные файлы без `documentScope` отклоняются для защиты от смешения черновиков.

Выполнение происходит целиком в браузере, без отправки JSON на сервер. Допускается до 256 КиБ и не более 100 фигур. Геометрия, текст, типы фигур, цвет, толщина линий и ссылки подтверждений проверяются до изменения редактора. Пользователь видит отдельное подтверждение замены **текущего ручного слоя**; старый слой доступен через Undo. Ручные назначения и решения по связям восстанавливаются при корректных ссылках, но повторно проверяются текущим геометрическим аудитом — неоднозначные связи не становятся подтверждёнными.

Никакого OCR/LLM/VLM, загрузки моделей, миграций базы, изменения оригинального DOCX и автоматического применения схемы к книге нет. Этот импорт готовит проверяемый фундамент для будущих предложений распознавания, но НЕ принимает предложения ИИ без проверки.

## Проверки
1. `node --check app/static/diagram_import.js`, `node --check app/static/diagram_graph.js`, `node --check app/static/docwork_workbench.js`.
2. `node --test tests/diagram-graph.test.cjs tests/diagram-import.test.cjs` — ожидается 19 успешных проверок (14 прежних + 5 новых).
3. Прежний `scripts/docwork-image-host-smoke.py` — 27 проверок.
4. В браузере открыть тестовый DOCX, нарисовать фигуры и подписи, подтвердить связь, экспортировать JSON, сбросить ручные изменения, импортировать экспорт, проверить слой, решения и Undo.
5. Попробовать чужой черновик, другой рисунок, ошибочный JSON, превышение лимитов; импорт должен быть отклонён.
6. Проверить, что исходный DOCX не меняется и успешное удаление книги из библиотеки не нарушено.

## Ограничения
Перенос между разными DOCX или заменёнными изображениями **запрещён** этим режимом импорта. Для этого в будущем потребуется отдельная безопасная функция сопоставления изображений и правок. Совместимость старых экспортов без идентификатора назначения не обещается. При полном удалении черновика сохранённый JSON не станет инструментом восстановления исходного DOCX.
