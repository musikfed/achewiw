# R3.2 — Единый редактор текста и рисунков в ACHEWIW

Дата: 23 ноября 2026 года. Черновой PR №28 на основе проверенного R3.1.
Ссылка: https://github.com/musikfed/achewiw/pull/28

## Что изменилось

Редактор находится на той же странице DocWork — отдельное приложение или новая вкладка не требуются. В правой части одновременно находятся текстовые абзацы, изображения и подписи. Текст простых абзацев и подписи можно редактировать прямо на полотне. Рисунок можно перетащить мышью за рамку к промежутку перед другим абзацем; альтернативно выбрать его и щёлкнуть по месту вставки.

Изменение — не декоративный предпросмотр: Python-модуль app/docwork_image_moves.py перемещает реальные OOXML-абзацы картинки и её подписи в новой копии DOCX. Позиции, текст и стили сохраняются в истории R3, включая восстановление после F5. Исходный DOCX не изменяется. Оформление R3.1 — процент ширины текстовой области, горизонтальное выравнивание, прозрачные скруглённые углы — доступно и на полотне.

## Ограничения

Это редактор потока текста, а НЕ полная замена Word с абсолютным перемещением рисунка по X/Y или обтеканием произвольного контура. Картинки перемещаются как отдельные блоки перед выбранным текстовым абзацем либо в конец. Сложные плавающие объекты, картинки в таблицах, рисунки рядом с текстом внутри одного абзаца и документы с несколькими разделами Word не передвигаются автоматически. Визуальный поток не повторяет точную постраничную вёрстку: для неё необходимо открыть реальный PDF-предпросмотр.

В первой версии требуется исходник DOCX. PDF сначала преобразуется в DOCX с ограничениями R1. Интерфейс подгружает абзацы порциями по 120, в пределах первых 3000 записей структурного просмотра. Не затронутые абзацы сохраняются.

## Как проверить на Huananzhi

1. Дождаться успешного GitHub Actions PR №28; на работающем стенде сейчас предыдущая R3.1.
2. Проверить чистоту git status в /1tbdisk/achewiw.
3. Скачать ветку feature/docwork-inline-layout-20261123 и переключить checkout без reset и clean.
4. Штатной командой bash scripts/achewiw-control.sh rebuild пересобрать только контейнер ACHEWIW Studio; auth-check удостоверит HTTP 200.
5. Выполнить синтетический HTTP-тест:
   docker exec -i -w /app achewiw-studio python - < scripts/docwork-image-host-smoke.py
6. Открыть /docwork/ после Ctrl+F5. В тестовом DOCX изменить текст, перетащить рисунок между абзацами, отредактировать подпись, изменить размер и скругление. Нажать F5, проверить сохранение позиции и скачать результат DOCX/PDF.
7. Проверить файл в Word или LibreOffice и по реальным PDF-страницам, затем сообщить результат для записи в PR №28.

Установка моделей, GPU, Ollama, ComfyUI и изменение других проектов не нужны. Вся работа остаётся в одном ACHEWIW. Издательский нормативный допуск по-прежнему BLOCKED до R4 и ручной сверки.
