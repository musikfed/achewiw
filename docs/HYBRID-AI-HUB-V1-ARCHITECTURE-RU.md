## Концепция продукта

**ACHEWIW Hybrid AI Hub** — одно локальное рабочее место автора книги: рукопись, источники, редактура, изображения, версии, печать и выбор исполнителя для каждой роли. Локальные Ollama сохраняются; облачные LLM и Codex включаются явно. Система показывает использование ресурсов на уровне отдельного запроса, главы, книги и издательской серии.

Это не переписывание существующего ACHEWIW и не перевод всех книг в облако. «Облачные» вычисления — **опциональная** функция с выключенным по умолчанию доступом к авторскому тексту.

## Потоки

1. **Local-first:** роль «Писатель» может использовать `qwen3:8b`, «Критик» — `qwen3:4b-instruct`. Существующая последовательная GPU-аренда не меняется без проверки.
2. **Выбор облака:** автор назначает GPT / DeepSeek / Mistral / другие модели на роль, разрешает передачу конкретного фрагмента рукописи и устанавливает бюджет.
3. **Подготовка:** Router проверяет доступность, тариф, стоимость оценки, конфиденциальность и авторское разрешение.
4. **Выполнение:** один request ID связывает запрос, результат, провайдера, маршрут, расходы и фактического плательщика.
5. **Рецензирование:** результат ИИ — **предложение**, а не автоматическое изменение книги или канона.
6. **Экспорт:** PDF/DOCX/EPUB/FB2 выходят из принятой редакции без служебных комментариев.

## Модель подключения

| Тип подключения | Провайдеры | Учёт |
|---|---|---|
| Локальная LLM | Ollama | токены если доступны, VRAM/время |
| LLM API | OpenAI, DeepSeek, Mistral | вход/выход/кэш/вычисления + тариф |
| Ответ с поиском | Perplexity | токены и стоимость поисковых вызовов |
| Маршрутизатор моделей | Hugging Face | usage и **фактический счёт-плательщик** |
| Шлюз/вычисления | Cloudflare | Neurons/токены и Gateway usage без двойного счёта |
| GPU/model execution | Modal, Replicate | токены или compute/output units по конкретной модели |
| Notebook/batch | Kaggle | GPU-квоты и выполнение задания; не chat API |
| Агент | Codex SDK/CLI/app-server | отдельное разрешение на файловые действия и отдельный учёт |

Биллинговые тарифы и API-схемы меняются: точные поля и ставки перед кодированием проверяются в актуальных официальных документах, версии тарифов сохраняются.

## Основные сущности

- `ProviderConfig`: имя, режим, ссылка на секрет **без хранения самого секрета в БД**, включённые возможности и согласие автора.
- `ModelCatalogEntry`: идентификатор модели, роли, контекст, pricing strategy, ограничения.
- `RoutingDecision`: роль, модель, snapshot и одобрение на внешний вызов.
- `UsageEvent`: request ID, проект/книга/глава, input/output, cached/reasoning как подмножества, non-token units, цена estimated/confirmed, неизвестные поля.
- `BudgetPolicy`: дневной/месячный/книжный предел, причина блокировки, ручное разрешение на продолжение.
- `AgentPermission`: изолированное окружение Codex, разрешённые каталоги, доступ в сеть, ручной просмотр diff.
- `ManuscriptRevision`: неизменяемая редакция, заметки отдельно, принятое изменение, выходные файлы.

## Порядок реализации (по одному проверенному блоку)

| Этап | Результат | Гейт |
|---|---|---|
| 0 | аудит и ADR | нет скрытых изменений базы/сервера |
| 1 | Router + Ollama + mock provider | старые книги и экспорт не изменились |
| 2 | OpenAI/DeepSeek + локальный Ledger | числа usage воспроизводимы |
| 3 | UI: подключение и токены/стоимость | ключей нет в браузере и логах |
| 4 | Mistral/Perplexity/HF/Cloudflare | правильные тарифы, без double billing |
| 5 | Modal/Replicate/Kaggle | не-токенные единицы отдельно |
| 6 | Codex agent + редакторские заметки | автор принимает каждое действие |
| 7 | QA, release gate, PR | никаких автоматических merge/deploy |

## Что недопустимо

- Автоподключение облака, скрытая отправка содержимого книги.
- Объединение подписки ChatGPT с API-биллингом или обход лимитов.
- Перезапись исходной рукописи или канона.
- Автоматический запуск Codex с полномочиями на сервер и соседние проекты.
- Удаление `data/`, разрушительные миграции, переразметка всех страниц A5 из-за одной редакторской правки.
- Изображение demo-токенов как реального API-баланса.
- Выпуск под статусом «полностью готово», когда коннекторы ещё не реализованы.

**Итог:** новая редакция расширяет «Типографию в кармане» до гибридной платформы, оставляя авторский контроль и локальную автономность первыми принципами.
