# Безопасный запуск ACHEWIW и запуск одного продуктового цикла

## Состояние системы

В репозитории **уже существует** собственная студия ACHEWIW с локальным книжным конвейером. Данный документ **не** устанавливает бухгалтерскую подсистему, автоматическую SEO-публикацию или торгового агента. Это порядок организации ручных запусков и будущих улучшений.

## Проверить работающий сервер CORE (без переустановки)

На Ubuntu CORE, только если уже существует рабочий каталог /1tbdisk/achewiw:

~~~bash
cd /1tbdisk/achewiw
git status --short
bash scripts/achewiw-services.sh status
bash scripts/prepare-conveyor-models.sh status
ollama ps
nvidia-smi
~~~

Если есть неожиданные изменения, активная GPU-работа или недоступный сервер — остановить процедуру и сначала диагностировать. **Не использовать reset --hard, clean, глобальные docker-команды или операции с рабочей data/.**

## Запустить только текущую Studio

~~~bash
cd /1tbdisk/achewiw
bash scripts/achewiw-services.sh start
bash scripts/achewiw-services.sh status
~~~

Графику запускать отдельно только по осознанному решению: **scripts/achewiw-services.sh graphics-start** при свободной GPU и проверенных сервисах. В веб-интерфейсе использовать существующий раздел **«06 · Типография → Издательский конвейер»**, выбрать уже установленные модели, проверить результаты QA, утвердить текст лично. См. [README](../README.md) и [технический конвейер](../docs/CONVEYOR-RTX3060-RU.md).

## Первый продуктовый цикл

1. Локально скопировать пустой шаблон SKU и задать жанр/читателя/права/бюджет.
2. Вручную передать в модель P0 из [промптов](03-prompts.md), затем P1. Утвердить каркас.
3. Пройти фактический конвейер текущего приложения; не заявлять о готовности неиспытанных функций.
4. Сделать QA, проверить сохранение подписи к каждому изображению, выходной PDF/EPUB/DOCX, лицензионные материалы.
5. Утвердить релиз лично. Публиковать через официальный кабинет Литрес или другого сервиса.
6. Записать реальную ссылку, проверенные расходы и KPI. Предложения по SEO — только черновик.
7. Через месяц сверить роялти и выплаты и выполнить P8 с **обезличенной** копией данных.

## Запреты

Никаких платежей, чеков, изменения налогового статуса, автопубликации, удалённых деплоев, выполнения AI-кода, перепрошивки камеры/робота по тексту LLM. Не использовать внешнюю модель для уверенного заявления об эксперименте без измерений и не переписывать ранее утверждённые главы без решения автора.

## Обновления существующего проекта

Весь данный план — только новые markdown/svg/csv файлы внутри папки. Он **не требует перезапуска, миграции данных, нового Docker-контейнера или скачивания моделей**. Для будущих функций нужны отдельные спецификации, тесты, обратимые изменения, владелец и согласованный релиз. Перед любым реальным обновлением сервера следовать существующим инструкциям, сохранить активные задачи и данные.
